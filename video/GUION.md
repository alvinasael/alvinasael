# GLP-1: el mensajero que tu cuerpo ya conoce

Video vertical (1080×1920), 77 s, texto en pantalla, sin voz.
Fuente editable: `glp1-video.html` (ábrelo en el navegador para verlo; `?t=30` muestra un cuadro fijo).
Para volver a grabarlo: `node render.js` (requiere Playwright y ffmpeg).

| Tiempo | Texto en pantalla |
|---|---|
| 0–6 s | Tu cuerpo ya produce GLP-1. Cada vez que comes, tu intestino lo suelta. |
| 6–13 s | Es una hormona mensajera: avisa que llegó comida. Pero la natural dura apenas unos minutos. |
| 13–20 s | El medicamento GLP-1 es una copia que dura mucho más. Por eso muchas se aplican una vez por semana. |
| 20–27 s | Al páncreas le dice: suelta insulina, pero solo cuando la glucosa está alta. |
| 27–32 s | Al hígado: suelta menos azúcar. |
| 32–37 s | Al estómago: vacíate más despacio. |
| 37–42 s | Y al cerebro: ya estás lleno. |
| 42–46 s | Tres historias que se juntan en una sola. |
| 46–51 s | Uno: más insulina, justo cuando hace falta. |
| 51–56 s | Dos: menos azúcar saliendo del hígado. |
| 56–61 s | Tres: la comida entra más despacio. |
| 61–67 s | Juntas logran lo principal: una glucosa más estable, después de comer y en ayunas. |
| 67–74 s | Y como beneficio adicional: menos apetito y, para muchas personas, menos peso. Algunos GLP-1 también protegen el corazón y los riñones. |
| 74–77 s | Cierre con el logo. |

Los valores de glucosa (156 → 138 en ayunas, 232 → 180 después de comer) son ilustrativos.
Pendiente de revisión clínica: la frase sobre corazón y riñones.
